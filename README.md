# Боря-биток

Мини-игра «американский бильярд», где вместо битка — голова Бори.

Сейчас готово превью модели и анимаций: `index.html` (Three.js из CDN).

Запуск локально (нужен любой статический сервер из-за ES-модулей):

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000

- `js/head.js` — процедурная 3D-модель головы, выражения лица, качение, сквош, физика серёжек
- `js/fx.js` — эффекты: звёздочки, «БАЦ!», кольцо удара, звёзды над головой
