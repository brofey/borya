# Боря-биток

Американский пул («восьмёрка») на Three.js, где вместо битка — голова Бори.
Каждый удар оставляет синяк — навсегда (хранятся в браузере, в меню можно «вылечить»).

- `index.html` — игра: против компьютера или вдвоём на одном экране
- `preview.html` — превью модели и анимаций

Управление: веди пальцем/мышкой — прицел, ◀ ▶ / стрелки — точная доводка,
ползунок справа вниз и отпустить (или держать пробел) — удар, `C` — вид сверху.

Локально (нужен статический сервер из-за ES-модулей):

```bash
python3 -m http.server 8000
```

## Код

- `js/game.js` — игровой цикл, правила восьмёрки, ИИ, камера-преследователь, синяки
- `js/head.js` — процедурная голова: выражения лица, качение, сквош, серёжки, синяки на коже
- `js/table.js` — стол, лузы, борта, шары, кий
- `js/physics.js` — физика шаров
- `js/fx.js` — эффекты, `js/audio.js` — синтезированные звуки
